# 📋 Changelog — Coach Manager PWA

## v3.0 — גרסה נוכחית (יולי 2026)

### חדש ב-v3.0
- **מערכת דרגות פיצ'רים (Feature Tiering)** — Basic / Pro / Enterprise
  - `FeatureService` + `FeatureGate` component
  - טבלת `tenant_subscriptions` ב-Supabase
  - חסימת רכיבים לפי דרגה (הסתרה / נעילה)
- **שליחת מייל ברכה למאמן חדש** דרך Brevo API
  - תבנית HTML מעוצבת עם לוגו + פרטי כניסה
  - הגדרות דרך `appsettings.json` + GitHub Secrets
- **הסרת דרישת אימות אימייל** — משתמש נוצר מאומת מיד
- **הודעות שגיאה משמעותיות** במחיקת מאמן (FK constraints)
- **תיקון מחיקת שיבוץ** (ניתוק coach_rate_id לפני מחיקת תעריפים)
- **ייצוא סקריפט גיבוי לקוחות** (SQL) — תחת FeatureGate Pro

## v2.0 (יוני–יולי 2026)

### ניהול בסיסי
- ניהול מאמנים (CRUD, לו"ז מועדף, אזורי זמינות, מעמד מיסויי)
- ניהול לקוחות ומוסדות (CRUD, סוגי לקוח, המלצת מאמנים לפי אזור)
- ניהול שיבוצים (CRUD, לו"ז שבועי, סטטוסים, סינון)
- ניהול חוזי התקשרות (חוזים ללקוח, שעות, תעריפים, לו"ז מועדף)
- ניהול תעריפים למאמנים (תעריף בסיס, תעריף לשיבוץ)

### חוזים וחתימה דיגיטלית
- הפקת חוזה HTML דינמי ממערכת + חותמת עסק
- שליחת חוזה לחתימת מאמן (סטטוס Pending → Signed)
- חתימה דיגיטלית על Canvas (מובייל + דסקטופ)
- שמירת חוזה חתום ב-Supabase Storage + מסמכי מאמן
- צפייה בחוזה חתום מתוך ניהול שיבוצים

### דיווחי שעות
- דיווח שעות מאמן (תאריך, שעות, סיכום, מיקום GPS)
- אישור/דחיית דיווחים ע"י אדמין (Admin_Approved / Rejected)
- סטטוסים: Draft → Submitted → Admin_Approved / Rejected → Billed_Paid

### לוחות שנה
- לוח שנה שבועי למאמן (שיבוצים פעילים עם שם לקוח + כתובת)
- לוח שנה שבועי לאדמין (סינון לפי מאמנים, צבעים לפי מאמן)

### הערכות וקבוצות
- מערכת הערכות לתלמידים
- ניהול קבוצות ותלמידים

### מסמכים ומשאבים
- ניהול מסמכי מאמן (העלאה, צפייה, מחיקה)
- מאגר משאבים והדרכה (TrainingHub)

### ממשק משתמש
- MudBlazor RTL עברית
- תמיכה במובייל (DataLabel על טבלאות, CSS RTL fixes)
- PWA עם Service Worker
- דשבורד אדמין עם סטטיסטיקות

### תשתית
- Supabase (PostgreSQL + Auth + Storage + RLS)
- Blazor WebAssembly (.NET 10)
- GitHub Pages deployment
- שירות נפות (LocalityService) — המלצת מאמנים לפי אזור גיאוגרפי

### תיקונים ושיפורים (v2.0)
- הודעות שגיאה משמעותיות במחיקת מאמן (FK constraints)
- תיקון מחיקת שיבוץ (ניתוק coach_rate_id לפני מחיקת תעריפים)
- ולידציית הקצאת שעות (חוזה חובה, שעות לא חורגות מחוזה)
- תיקון autocomplete בטלפונים (ClientDialog)
- ייצוא סקריפט גיבוי לקוחות (SQL)

## v3.0 — מתוכננת

### מערכת דרגות פיצ'רים (Feature Tiering)
- 3 דרגות: Basic (0) → Pro (1) → Enterprise (2)
- קומפוננטת `<FeatureGate>` לחסימת רכיבים לפי דרגה
- `FeatureService` — טעינת דרגה מ-DB, בדיקות הרשאה
- טבלת `tenant_subscriptions` ב-Supabase
- דף השוואת דרגות ושדרוג
- חיבור תשלום (Stripe/PayPal) — עתידי
- ראה: [FeatureTiering.md](FeatureTiering.md)

### מערכת דוחות (7 דוחות)
- דוח #1 — תשלום חודשי למאמן
- דוח #2 — סיכום שנתי למאמן
- דוח #3 — רווחיות (הכנסות מול הוצאות)
- דוח #4 — ניצול מכסת שעות
- דוח #5 — נוכחות/פעילות מאמנים
- דוח #6 — חיוב ללקוח
- דוח #7 — השוואה תקופתית
- ייצוא Excel (ClosedXML)
